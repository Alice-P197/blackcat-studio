# 小黑喵创作台 V3 · Notion 版

在 V2（v2.7.0）基础上**追加**了一个自包含的 Notion 模块。**V2 原文件一个字都没改**，V3 是独立的新文件。

## 怎么用

1. 双击 `blackcat-v3.html`，用浏览器打开（需要联网，MathJax / marked / highlight.js 走 CDN）
2. 工具栏点 **Notion** 按钮
3. 第一次用：去 <https://www.notion.so/developers/tokens> 建一个 PAT（能力勾 **Notion API**，有效期选 7 天），粘进面板点「保存」
4. 搜索 → 点一篇笔记 → 「导入到编辑器」
5. 在创作台里调排版（主题/字体/公式框等，都是 V2 原有能力）
6. **Ctrl+Shift+C** 一键复制 → 粘到微信公众号编辑器
7. 回到 Notion 面板点「标记为已发布并回写」→ 发布记录自动追加到那篇笔记末尾（**自动沉淀**）

## 导入时自动处理了什么

| Notion 那边 | 创作台里 |
|---|---|
| 正文文字 | 直接通过 |
| 行内公式 `$…$`（读回是 `` $`…`$ ``） | 还原成 `$…$`，由 MathJax 输出 **SVG**（微信要求） |
| 区块公式 `$$…$$` | 原样保留，同样输出 SVG |
| `<callout icon="…">` | `:::tip` / `:::note` / `:::warning` / `:::success` |
| `<table>` / 管道表格 | markdown 管道表格 |
| `<details><summary>` 折叠块 | `:::note` 容器（创作台没有折叠块） |
| `<span color="…">` 高亮 | `<font color="…">` |
| 图片（Notion S3 上的） | **下载 → base64 → `imageStore` → 正文写【图片N】占位符** |
| `<mention-page>` 页面提及 | 去掉标签只留文字 |
| `\[1\]` 转义方括号 | 还原成 `[1]` |

## 为什么图片一定要转 base64

微信编辑器的正文里**不能引用外部图片**，粘进去的图必须是内嵌数据或在微信自己的素材库里。所以 V3 在导入时就把 Notion 的图抓下来转成 base64，交给创作台原有的 `convertBase64Images()` 管线处理（这条管线 V2 里本来就有，V3 直接复用）。

**实测注意事项**：Notion 的图在 `prod-s3-us-west-2` 上，本机拉取的**单张连接延迟约 2～3 秒**（瓶颈是延迟不是带宽）。所以 V3 用了 **6 路并行 + 会话内缓存**：

- 12 张图的笔记：并行约 11 秒（串行预计 35 秒）
- 面板会实时显示「下载图片 3/12，约还需 8s」
- 重复导入同一篇不会重新下载

## 已知边界

- **搜索有索引延迟**：刚在 Notion 新建/改名的页面，搜索里可能要等十几秒才出现。
- **图片下载失败**会保留原 URL 并在状态栏提示——预览能看到，但复制到微信会失效，需要重导。
- **Notion 的公开图片链接 1 小时过期**，所以不要隔很久再导。
- **Token 存在浏览器 localStorage**（键 `xhm_notionToken`），只在本机，不上传任何服务器。PAT 建议设短期有效期，用完可随时吊销。
- V3 需要联网打开（CDN 依赖与 V2 相同）。

## 面板第 ⑤ 节：两条出口

V3 给了两条把文章送进公众号的路，按文章长短自选：

| | 一键复制（Ctrl+Shift+C） | 推送到草稿箱 |
|---|---|---|
| 原理 | 内联样式 HTML + MathJax SVG 塞进剪贴板 | 本地助手调微信接口建草稿 |
| 大小限制 | **无** | **正文 < 2 万字符、< 1M** |
| 图片 | base64 直接粘（微信编辑器接受） | **base64 无效**，助手要先把图传到微信图床换成 `mmbiz.qpic.cn` URL |
| 发布 | 手动粘贴 + 手动点发表 | 草稿箱里直接出现，发表仍需手点（见下） |
| 前提 | 无 | 本地助手在跑 + IP 白名单 |

**所以公式密集型长文建议用「一键复制」，常规文章才走草稿箱。**

### 「导出草稿包(.json)」不需要助手

点一下下载 `blackcat-draft-<标题>.json`：含 `title`(≤32字) / `digest`(≤120字) / `html`(内联样式、已去 class/id) / `images`(base64 列表) / `sourcePageId`(供发布后回写 Notion)。这份包就是本地助手的输入。

### 「推送到公众号草稿箱」需要本地助手

V3 会先探测 `http://127.0.0.1:8787/ping`；助手没启动时给出明确提示，不会静默失败。

## 关于「自动发表」——个人订阅号的硬限制

微信官方文档（`/cgi-bin/freepublish/*` 发布能力页）写明：

> 2025 年 7 月起，**个人主体账号、企业主体未认证账号及不支持认证的账号将被回收以上接口的调用权限**

而 `draft/add` 文档对 `content` 的约束是：

> 必须少于 2 万字符、小于 1M，此处会去除 JS，涉及图片 url **必须来源「上传图文消息内的图片获取 URL」接口获取。外部图片 url 将被过滤。**

结论：**个人订阅号做不到全自动发表**。能争取到的最好结果是「一键推进草稿箱 + 手机上点一下发表」。另外微信接口不支持 CORS，所以必须有本地助手进程（顺带解决 IP 白名单）。

**IP 白名单注意**：如果本机走 VPN / 代理，出口 IP 会变；VPN 重连后调微信接口会报 `40164`，需去公众号后台把新出口 IP 重新加进白名单。

## 改动 V3 的正确姿势

不要直接编辑 556 KB 的 `blackcat-v3.html`。改 `v3-notion-module.js`，然后跑：

```powershell
node ..\build_v3.js      # 重新组装，会自动校验注入模块与源码逐字节一致
node ..\test_v3_e2e.js   # 端到端回归（会自建测试页并在结束时丢进回收站）
```

> 组装脚本里有一处坑已修好：**必须用函数式替换**。模块里的公式正则含 `` $` ``，如果直接当替换字符串传给 `String.replace`，会被展开成"匹配位置之前的全部内容"，导致整篇文档被复制一份并破坏 JS。
