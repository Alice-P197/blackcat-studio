✨ v3.0 更新内容

  • Notion 模块：搜索 / 导入 Notion 笔记，行内公式、callout、表格、图片自动转换（图片转 base64，微信可用）；发布后可一键回写 Notion 沉淀发布记录
  • 桌面版（Electron）：主进程代理全部 API 调用——无 CORS 限制，Notion Token / 公众号 AppSecret 经 Windows DPAPI 加密存储，网页侧拿不到原文
  • 一键推送公众号草稿箱：图片自动传微信图床、封面传永久素材、正文自动体检（2 万字符 / 1M 限制），长文走 Ctrl+Shift+C 一键复制
  • 局域网服务：桌面版一键开启后，手机连同一 Wi-Fi 打开 http://电脑IP:8899 即可在手机上导入与排版（浏览器模式降级为只读导入）
  • 文稿库：多篇文稿管理，自动保存到本机，关掉应用不丢
